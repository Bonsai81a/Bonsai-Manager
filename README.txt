BONSAI MANAGER – lokale installierbare Web-App

INHALT
- index.html: App
- manifest.webmanifest: Installationsdaten
- sw.js: Offline-Cache
- icon-192.png / icon-512.png: App-Symbole

WICHTIG
Die App speichert Daten im lokalen Speicher des Browsers auf dem jeweiligen Gerät.
Sie synchronisiert NICHT automatisch mit anderen Geräten. Regelmäßig unter
„Datensicherung“ eine JSON-Sicherung herunterladen.

INSTALLATION AUF SAMSUNG / ANDROID
1. Die Dateien müssen auf einer HTTPS-Webadresse bereitgestellt werden
   (z. B. auf einem eigenen Webspace). Ein bloßes Öffnen der HTML-Datei aus
   dem Download-Ordner reicht für die PWA-Installation nicht aus.
2. Die HTTPS-Adresse in Chrome auf dem Samsung-Handy öffnen.
3. Chrome-Menü (⋮) > „App installieren“ oder „Zum Startbildschirm hinzufügen“.
4. Das Symbol „Bonsai“ erscheint anschließend auf dem Startbildschirm.

ERSTER START
„＋ Bonsai“ wählen und die Bäume einzeln eintragen. Pflegeeinträge und Aufgaben
lassen sich anschließend direkt zuordnen.
